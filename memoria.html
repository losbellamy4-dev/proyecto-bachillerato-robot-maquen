      1Introducción

      ¿De qué trata el proyecto?

      He construido un coche robot que se maneja desde el móvil. La idea es usar la tecnología para aprender normas básicas de seguridad vial: frenar a tiempo, avisar con las luces y la bocina, y detenerse ante un obstáculo.

      El coche es un robot Maqueen con una placa micro:bit. El mando a distancia es una página web que se abre en el móvil y se conecta al coche por Bluetooth.

      Qué he aprendido

      Electrónica básica, programación por bloques y cómo se hace una página web.

      Relación con la seguridad vial

      El coche frena solo si detecta algo delante, como el frenado de emergencia de algunos coches actuales.

      2Objetivos

      Qué quería conseguir

      Objetivo general: construir un coche robot que se pueda controlar desde el móvil y que tenga medidas de seguridad.

      • Programar el micro:bit

        Para que entienda las órdenes que le llegan por Bluetooth y mueva el coche.

      • Crear la app de control

        Una página web para manejar el coche desde el móvil.

      • Añadir seguridad

        Que el coche frene ante un obstáculo y se pare si se pierde la conexión.

      4Funcionamiento

      Qué pasa cuando pulsas un botón

      1. Pulsas un botón en la app

      Por ejemplo, la flecha de avanzar.

      2. El móvil envía una orden

      Manda por Bluetooth una palabra, como avanzar.

      3. El micro:bit la entiende

      Su programa compara la palabra con las órdenes que conoce.

      4. El coche se mueve

      El micro:bit enciende los motores en la dirección correcta. Al soltar el botón, la app envía parar.

      5MakeCode

      Programación del micro:bit

      El micro:bit se programa con MakeCode, una web donde se programa con bloques. Añadí dos extensiones: Bluetooth y Maqueen. El programa tiene tres partes:

      • · Al iniciar: activa el Bluetooth y deja el coche parado.
      • · Al recibir una orden: mira qué palabra ha llegado y hace lo que corresponde.
      • · Por siempre: si el modo seguridad está activado y hay algo a menos de 10 cm, frena.

      Estas son las órdenes que entiende el coche:

      OrdenQué hace
      avanzarEl coche va hacia delante
      atrasEl coche va hacia atrás
      izquierdaGira a la izquierda
      derechaGira a la derecha
      pararSe detiene
      vel + númeroCambia la velocidad, de 0 a 100 (por ejemplo, vel75)
      bocinaHace sonar un pitido
      lucesEnciende o apaga las luces
      seguridadActiva o desactiva el frenado automático
      6La app

      La app de control

      La app es una página web en un solo archivo. El HTML forma la estructura, el CSS le da el aspecto y el JavaScript se encarga de conectar por Bluetooth y enviar las órdenes. Para escribir el código me ayudé de Claude, una IA, y de lo que aprendí en un curso básico de programación.

      La app tiene:

      • · Un botón para conectar con el coche.
      • · Unas flechas: mientras mantienes una pulsada, el coche se mueve; al soltarla, para.
      • · Un botón rojo de PARAR.
      • · Un deslizador para la velocidad.
      • · Botones de bocina, luces y seguridad.
